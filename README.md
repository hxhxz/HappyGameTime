# 璀璨宝石 · 宝可梦规则引擎陪练

1 位真人 + 3 位本地规则 agent 的私人训练桌。赤焰偏重抢分，青岚偏重进化，紫苑偏重控场。

- 独立的规则引擎校验与合法动作枚举
- 本地确定性决策，不调用外部模型或产生 API 费用
- 128K 上下文安全上限：预留 4K 推理/输出预算与安全余量，只保留最近 8 条动作，避免旧状态干扰决策
- 独立访问口令、自动存档、决策说明、暂停与重试
- 一键导出 JSON 复盘记录，包含合法候选、规则评分分项、最终选择与说明
- 双入口：零模型依赖的规则游戏，以及按席位配置的 LLM 重排实验
- Regret 标注、门控记录、诚实 POMCP 与座位轮换配对评测
- 固定四人桌，18 分终局、进化、稀有与传说卡
- 支持容器化私有部署和子路径反向代理

运行、部署、验证范围与已知限制见 [DEPLOYMENT.md](DEPLOYMENT.md)。
